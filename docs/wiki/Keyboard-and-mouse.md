# Keyboard and mouse

**Help > About and shortcuts** shows the keys in the app.

## Mouse in the 3D view

| Input | Action |
|---|---|
| Left drag | Turn the view around the model (orbit) |
| Right drag or middle drag | Move the view to the side (pan) |
| Shift + left drag | Move the view to the side (pan) |
| Wheel | Move nearer or farther (zoom) |
| Double click | Fit the model in the view, or the part in focus |
| Click on a part | Select the part. In the Optimize tab, select the print part. With **Select face** on for the selected part, a click on that part puts the clicked face on the bed. |
| Click on the background | Clear the selection |
| Right click on a part | In the Model and Render tabs: open the part menu: **Focus**, **Change color…** |

## Keys

The keys do nothing while a text field has the focus. Point to a tab name to see its key.

| Key | Action |
|---|---|
| `F` | Fit the model in the view, or the part in focus. In the Optimize tab, show the full bed. |
| `F5` | Build now |
| `W` | Wireframe on or off |
| `E` | Explode the parts, on or off |
| `O` | Open the Optimize tab. Press again to go back to the Model tab. |
| `R` | Open the Render tab. Press again to go back to the Model tab. |
| Up / Down | In the Optimize tab: the next or the previous layer |
| PgUp / PgDn | In the Optimize tab: 10 layers up or down |
| Esc | Clear the selection and leave the focus. Close a menu or a window. |

## Keys for the menus and the app

| Key | Action |
|---|---|
| Ctrl+N | Make a new model |
| Ctrl+O | Open a file |
| Ctrl+, | Settings |
| Ctrl+Q | Quit |
| Alt+F | Open the File menu |
| Alt+M | Open the Model menu |
| Alt+V | Open the View menu |
| Alt+H | Open the Help menu |

## Keys in the welcome tour

| Key | Action |
|---|---|
| Left / Right | Go to the step before or the next step |
| Enter | Go on. At the last step, close the tour. |
| Esc | Close the tour |

## The menus

| Menu | Commands |
|---|---|
| **File** | Open…, Examples, Recent models, Clear list, Settings, Quit |
| **Model** | Build now, Auto build, Export STL (binary), Export 3MF, Export STEP (AP214, faceted). For a model with named parts, also the multicolor 3MF exports. |
| **View** | Model, Optimize, Render, Fit, Iso, Top, Front, Right, Wireframe, Grid, Explode, OpenSCAD console |
| **Help** | Welcome tour, GitHub page, About and shortcuts |
