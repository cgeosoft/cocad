Privacy Notice

Notice version 2. Last updated: November 8, 2026

Summary

  • The desktop app has two options: usage analytics and error reports. Each option is a separate choice. Both are off until you turn them on.
  • The app works the same way if you leave both options off.
  • The app never sends your models, file names or parameter values.
  • The website uses PostHog analytics only if you accept them. It sets no cookies. It has no forms and no accounts.

Who is responsible

Christos Georgiou (cgeosoft) is the controller of this data. Contact: christos@cgeosoft.com.

The desktop app

CoCAD has no account. The app asks you about the two options at the first start, and again if this Notice changes what the app sends. Until you answer, it sends nothing. To change your choice, open File > Settings. A change applies at once.

OptionWhyWhat the app sendsExample
Usage analyticsTo see which features people use, so that we can improve themFeature events: app started, model opened with the number of parameters, model exported with the format, view changed, photo saved with the sample count. Each event also has a random install ID, the app version, the operating system, the processor type and the notice versionapp_started, view: model, first_run: false, version 0.3.1, linux, x86_64, ID 3f9a...
Error reportsTo find and repair failuresWhen the app fails: the error type, a fixed code for the failure point, the location in our own source code, the app version, the release channel, the operating system, the processor type and the notice versionpanic, window:panic, cocad::app::App::open, src/app.rs line 42, version 0.3.1, linux, x86_64

The legal basis for each option is your consent (GDPR Art. 6(1)(a)). You can withdraw it at any time in File > Settings.

An error report holds no install ID and no error message. Each report has a new random ID, so a report does not link to your analytics or to another report.

The app does not send model contents, file names, parameter values or OpenSCAD output. PostHog sees your IP address during the connection and does not store it. The app tells PostHog not to look up your location.

Only the app window sends data. The params, export, slice and photo commands send nothing, and the cocad mcp process sends nothing. If you connect an MCP client, the window sends the same data as when you use it yourself, if you turned the options on.

Website analytics

The site loads PostHog only after you accept. If you decline, the page makes no request to PostHog.

After you accept, the site sends these events: page view, download click (system and file type) and demo prompt (example model). Each event has a random ID and the notice version. An event does not hold the page address, the referring page or your browser type. The site does not record your clicks in general, your keystrokes or your session.

Change your website choice

You can change your choice at any time. When you decline, the site stops the analytics and removes the PostHog ID from your browser.

Who receives the data

PostHog receives this data for us, as our processor. App and website data go to the same PostHog project. The app ID and the website ID are different, and we do not link them.

We use PostHog Cloud EU, which stores data in Germany. The data can also leave the EU: the PostHog sub-processor list names Cloudflare for traffic at global edge locations, and PostHog companies in Germany and the United Kingdom. PostHog, Inc. is the parent company. That list can change.

How long the data stays

PostHog keeps usage analytics, website events and error reports for up to 12 months. PostHog can delete expired events some time after that date. If you ask for erasure, removal runs in batches and can take time.

Your rights

You can ask for access to your data, and for its correction or erasure. You can object to its use, and you can withdraw consent at any time. You can also complain to your data protection authority.

To make a request, write to christos@cgeosoft.com.

  • Usage analytics: your request must give the install ID. The ID is in File > Settings. It stays there when you turn analytics off. Copy it before you press Reset, because without it we cannot find your data.
  • Error reports: a report has no ID that leads to you, so we cannot find the reports of one person.
  • Website analytics: the ID is only in your browser, and we cannot link it to you. To remove it from your browser, decline the analytics. Its events expire after the period above.

Changes

This page shows the notice version and the date of the last change. If the data, the purpose or the recipient changes, the version goes up, and the app and the site ask you again.
